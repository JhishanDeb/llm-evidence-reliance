# LLM Evidence Reliance

Do LLMs reason with model explanations (SHAP), or defer to them one way?

This study is pre-registered. The protocol is in PREREGISTRATION.md (release prereg-v1). Later deviations are dated in the same file (releases prereg-v1.1 to prereg-v1.3).

## Repository layout

- `PREREGISTRATION.md`: the registered protocol and the deviations D1 to D5.
- `analysis/`: the simulations behind Deviation D1, with their outputs.
- `code/`: all code and notebooks (dev phase, main runs, registered analysis).
- `results/dev/`: output of the dev phase, used only for engineering checks.
- `results/main/`: raw outputs of the four main runs and the registered analysis (`report.md`).
